# NEXA CAM

Professional Android Camera Application.

## Features

- Native Android camera preview
- Photo capture
- Video recording
- Front and back camera switching
- Flash and torch controls
- Dark black and red interface
- Automatic APK build with GitHub Actions

## Technology

- Kotlin
- Android CameraX
- Gradle
- GitHub Actions

## Package

com.nexa.cam

## Build

Push the project to the main branch.

Open the Actions tab and check the Build NEXA CAM APK workflow.

After a successful build, download the NEXA-CAM-APK artifact.

## Note

This is an initial development version.
Advanced manual controls, lens selection, cinematic
filters, and additional camera features are planned.
